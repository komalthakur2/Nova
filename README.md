# 🌟 Nova

An advanced full-stack **AI-powered content generation platform** that helps users create articles, generate images, remove objects/backgrounds, and review resumes — all in one place.

Built using **React + Clerk + Node.js + PostgreSQL**, and deployed on **Vercel**.

---

## 🚀 Features

### 🧠 AI Tools
- ✍️ **AI Article Writer** — Generate professional blog articles and titles.
- 🖼️ **AI Image Generator** — Create 3D,realistic etc AI-generated images.
- 🧹 **Remove Background/Object** — Upload and clean up images instantly.
- 📄 **Resume Review** — Upload a resume PDF and get AI-based analysis.

### 💜 Community & Dashboard
- 👥 **Community Page** — View and like other users' published creations.
- 🧾 **Dashboard** — Manage your creations easily.
- 💎 **Premium Plan** — Access advanced AI tools with Clerk authentication.

---

## 🏗️ Tech Stack

| Layer | Technology |
|-------|-------------|
| **Frontend** | React + Vite + TailwindCSS |
| **Auth** | Clerk |
| **Backend** | Node.js + Express |
| **Database** | PostgreSQL (Neon:cloud hosting) |
| **Deployment** | Vercel |
| **AI APIs** | Gemini / OpenAI |
